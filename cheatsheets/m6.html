1Arrays

An array is a run of consecutive memory cells of one type, under one name. Unlike a Python list it has a fixed size and a single element type.

int score[5] = {80, 100, 63, 84, 52};

80[0]
100[1]
63[2]
84[3]
52[4]
??[5] out of bounds

Valid indexes are 0 to size−1. C++ never checks: score[5] silently reads or overwrites some other variable's memory.

2Arrays and functions

One element vs the whole array

PassHeaderCallOriginal changes?
element, by valueint sq(int x)a[i] = sq(a[i]);only via the return
element, by refvoid sq(int &x)sq(a[i]);yes
whole arrayvoid f(int b[], int n)f(a, 10);yes (acts like by reference)
read-only arrayint f(const int b[], int n)f(a, 10);no, compiler blocks writes

The function receives the address of element 0 and forgets the length, so always pass the size. Call with the bare name: f(a, 10), never f(a[], 10). A size inside b[10] in the header is ignored.

sizeof trap

  • sizeof(a) / sizeof(a[0]) gives the element count only where a was declared.
  • Inside a function, b is really a pointer, so sizeof(b) is the pointer size (8).

3Linear search and selection sort

Linear search

int linearSearch(const int a[], int n, int key) {
    for (int j = 0; j < n; ++j)
        if (a[j] == key)
            return j;        // first match
    return -1;               // not found
}

Checks one by one. About n/2 comparisons on average, n in the worst case.

Selection sort

void sort(int a[], int n) {
    for (int i = 0; i < n; ++i) {
        int min = a[i], idx = i;
        for (int j = i + 1; j < n; ++j)
            if (a[j] < min) { min = a[j]; idx = j; }
        if (idx != i) swap(a[i], a[idx]);
    }
}

Each pass finds the smallest of the unsorted part and swaps it to the front. Green = in final place, outlined = just swapped.

6C-strings (char arrays)

A C-string is a char array that ends with the null character '\0'. Every function that reads it stops at that terminator.

char name[] = "John"; needs 5 chars

J[0]
o[1]
h[2]
n[3]
\0[4]
'A'one char
"A"two chars: 'A' and '\0'
'0'digit character, code 48
'\0'null character, code 0
char s[] = "Steve";
s[2] = 'o';                  // "Stove"
for (int i = 0; s[i] != '\0'; i++) …   // standard loop

Overwrite the '\0' and output runs on into garbage memory.

<cstring> functions

CallDoes
strlen(s)length, not counting '\0'
strcpy(dst, src)copy src into dst
strcat(dst, src)append src to dst

dst must have room for the result plus '\0'. == on C-strings compares addresses, and s = "hi"; does not compile: use the functions.

Module 6 traps

  • for (i = 0; i <= n; i++) touches a[n]: one past the end.
  • substr(3, 4) is 4 characters from index 3, not "index 3 to 4".
  • "PHP" < "Perl" is true: 'H' (72) < 'e' (101).
  • cin >> n; then getline reads an empty line. Call cin.ignore() between.
  • A 2D parameter without the column size does not compile.
  • A char array for "hello" needs size 6.
