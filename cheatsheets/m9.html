2The three containers

vector — dynamic array

#include <vector>
vector<int> v;                // empty
vector<int> w(5, 0);          // five zeros
v.push_back(3);               // add at end
v.pop_back();                 // remove last
v[0];  v.front();  v.back();
v.size();  v.empty();  v.clear();
v.insert(v.begin() + 1, 9);   // before index 1
v.erase(v.begin());           // remove first

Fast index access and fast add/remove at the end.

list — doubly linked list

#include <list>
list<string> L;
L.push_back("b");  L.push_front("a");
L.pop_back();      L.pop_front();
L.front();  L.back();  L.size();
L.sort();                     // member sort
L.remove("a");                // every "a"
list<string>::iterator it = L.begin();
it++;                         // only ++ / --
L.insert(it, "x");            // before it
it = L.erase(it);             // returns next

Fast add/remove at both ends and anywhere you hold an iterator. No L[2].

map — sorted key → value

#include <map>
map<string, int> book;
book["Amy"] = 5551234;        // insert or overwrite
book["Bob"]++;                // missing key starts at 0
book.count("Kit");            // 1 if present, else 0
book.find("Kit") == book.end(); // true if absent
book.erase("Amy");
book.size();

Like a Python dict, but keys are unique and kept in sorted order.

4Iterators

An iterator marks a position in a container and behaves like a pointer: *it is the element, it++ moves on. The same loop works for every container, which is why we use iterators instead of indexes.

The loop to memorise

vector<int>::iterator itr;
for (itr = v.begin(); itr != v.end(); itr++)
    cout << *itr << endl;

// swap vector for list: identical loop
list<int>::iterator it2;
for (it2 = L.begin(); it2 != L.end(); ++it2)
    cout << *it2;

// const container → const_iterator
void show(const list<string> &lst) {
    list<string>::const_iterator ci;
    for (ci = lst.begin(); ci != lst.end(); ++ci)
        cout << *ci << endl;
}

Iterator kinds

KindCan doContainers
Forward= ++ * == !=
Bidirectionalforward + --list, map
Random accessbidirectional + + - += -=, < > <= >=vector, arrays

Each kind can do everything the kinds above it can. So it + 3 and it < end only work on vector iterators; use != to stay portable.

5Walking a map

map<string, int> m;
m["pear"] = 3;  m["apple"] = 5;  m["fig"] = 1;

map<string, int>::iterator it;
for (it = m.begin(); it != m.end(); it++)
    cout << it->first << " " << it->second << endl;
// apple 5
// fig 1
// pear 3        ← sorted by key, not insertion order

Each element is a pair: first is the key, second the value. (*it).first is the same as it->first.

Word count in four lines

map<string, int> freq;
string w;
while (cin >> w) freq[w]++;
for (map<string,int>::iterator i = freq.begin(); i != freq.end(); i++)
    cout << i->first << ": " << i->second << endl;

Reading m[key] for a missing key creates it with value 0. To just test, use count or find.

6sort() and operator<

sort(first, last)

#include <algorithm>
vector<int> nums = {50, 10, 40, 20, 30};
sort(nums.begin(), nums.end());     // 10 20 30 40 50

int a[5] = {3, 1, 2, 5, 4};
sort(a, a + 5);                     // arrays too

L.sort();                           // list: member function

The range is [first, last): first included, last excluded. sort() needs random-access iterators, so it works on vectors and arrays but not on lists or maps.

Sorting your own type

class Record {
public:
    string name;
    int number;
};

bool operator<(const Record &a, const Record &b) {
    return a.name < b.name;     // how to order two Records
}

vector<Record> book;
sort(book.begin(), book.end()); // now works, by name

STL doesn't know how to compare your struct or class. Defining operator< tells it; it is also needed to use the type as a map key.

7The phone book, three ways

Two vectors

vector<string> names;
vector<int> numbers;
names.push_back(n);  numbers.push_back(x);   // add

for (int i = 0; i < names.size(); i++)       // search O(n)
    if (names[i] == n) cout << numbers[i];

A map

map<string, int> book;
book[n] = x;                     // add or update

if (book.count(n) > 0)           // search O(log n)
    cout << book[n];

Module 9 traps

  • vector<int> v; v[0] = 1; is wrong: v is empty. Use push_back.
  • No L[2] and no sort(L.begin(), L.end()) on a list.
  • *v.end() is undefined.
  • A const container needs const_iterator.
  • new list<string>() gives a pointer: ans->push_back(x).
  • Erasing while iterating: use the iterator erase returns.
