2Declare before you call

The compiler reads top to bottom and must know a function's name, parameter types and return type before the first call.

Option A: prototype on top

double larger(double x, double y);  // prototype: ends with ;

int main() {
    cout << larger(2.5, 5.0);
}

double larger(double x, double y) { // definition
    return (x >= y) ? x : y;
}

Option B: define above main

double larger(double x, double y) {
    return (x >= y) ? x : y;
}

int main() {
    cout << larger(2.5, 5.0);
}
Declaration / prototypeheader + ;, no body. Parameter names optional: double larger(double, double);
Definitionheader + body
Callname + arguments

void and return

void print_msg(int x) {     // no value back
    cout << x << endl;
}

int sign(int n) {
    if (n > 0) return 1;     // return ends the function
    if (n < 0) return -1;
    return 0;
}

A non-void function must return a value on every path. return; with no value is allowed in a void function to leave early.

4Pass by value vs pass by reference

By default C++ copies the argument into the parameter. Add & to the parameter and it becomes another name for the caller's variable.

When to use which

NeedUse
Only read the valueby value: int x
Change the caller's variableby reference: int &x
"Return" 2+ resultsreference out-parameters
Swap two variablestwo references
Argument is a literal like 5must be by value

A reference parameter needs a variable as the argument: square(5) does not compile with int &x.

Returning two values

void divide(int a, int b, int &q, int &r) {
    q = a / b;
    r = a % b;
}
int q, r;
divide(10, 3, q, r);   // q = 3, r = 1

void swap(int &a, int &b) {
    int tmp = a;
    a = b;
    b = tmp;
}

5Scope

In C++ every { } block makes a new scope (in Python only functions, classes and modules do). A variable exists from its declaration to the closing brace of its block.

Block scope and shadowing

int a = 1;              // main's a
{
    cout << a;          // 1  (inner a not declared yet)
    int a = 2;          // new a hides the outer one
    cout << a;          // 2
}
cout << a;              // 1  (inner a is gone)

if (true) { int x = 10; }
// cout << x;   ✗ x does not exist here

for (int i = 0; i < 3; i++) { }
// i does not exist here either

Scope at a glance

DeclaredVisible
outside all functionsglobal: everywhere below it
function parameterthat function's body only
inside a functionfrom that line to the function's }
inside { } / if / loopuntil that block's }
for (int i…)the loop only

Each call gets fresh local variables. Two functions can both have a local called x; they are different variables.

Module 5 traps

  • Calling a function above its definition with no prototype → "not declared in this scope".
  • A prototype needs the ;; a definition must not have one after ).
  • Changing a value parameter never affects the caller.
  • Missing return in a non-void function returns garbage.
  • An inner declaration with the same name hides the outer variable only inside that block.
  • pow returns a double: int x = pow(2, 3); converts it back.
