1Memory, addresses and pointers

Every variable lives in memory at an address. A pointer is a variable whose value is an address.

3Pointers as parameters

Swap through addresses

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
int x = 1, y = 2;
swap(&x, &y);           // pass the addresses

The pointers themselves are copied, but they hold the caller's addresses, so writing through them changes the caller's variables. This is how C does pass-by-reference (Module 10).

Three ways to write the same swap

StyleHeaderCall
value (doesn't work)swap(int a, int b)swap(x, y)
referenceswap(int &a, int &b)swap(x, y)
pointerswap(int *a, int *b)swap(&x, &y)

4Pointers and arrays

An array's name is the address of element 0. p[i] is exactly *(p + i), and p + 1 moves one element, not one byte.

Equivalent expressions

The value 3The address of t[3]
t[3]&t[3]
*(t + 3)t + 3
tPtr[3]tPtr + 3
*(tPtr + 3)&tPtr[3]
int *q = &t[2];   // q[0] is t[2], q[1] is t[3], q[-1] is t[1]
tPtr++;           // now points at t[1]
*tPtr++;          // read *tPtr, then move the pointer
(*tPtr)++;        // add 1 to the value pointed to

Walking an array with a pointer

int sum = 0;
for (int *p = t; p < t + 6; p++)
    sum += *p;

void salary_increase(int *sal, int n) {
    for (int i = 0; i < n; i++) {
        *sal = *sal * 1.1;
        sal++;
    }
}

You can move a pointer variable (p++), but not an array name (t++ is an error).

5Dynamic memory: new and delete

Local variables live on the stack and vanish when their function ends. new takes memory from the free store (heap) that lasts until you delete it.

new / delete pairs

AllocateFree with
int *p = new int;delete p;
int *a = new int[n];delete [] a;
Node *nd = new Node;delete nd;
int n;  cin >> n;
int *arr = new int[n];   // size chosen at run time
for (int i = 0; i < n; i++) arr[i] = i;
delete [] arr;

Two classic bugs

BugCauseExample
Memory leaklast pointer to heap memory lost before deletep = new int; p = new int;
Dangling pointerusing memory after it was deleteddelete p; *p = 3;

Set pointers to NULL after delete. Never return the address of a local variable: it dies when the function returns.

6Growing a dynamic array (the notes' ProductList)

Steps to add one more element

  1. Create a temporary array and copy the contents into it.
  2. delete [] the old array.
  3. Re-create it bigger with new.
  4. Copy the contents back from the temporary array.
  5. delete [] the temporary array.
  6. Put the new item in the free slot.
Product *tmp = new Product[n];
for (int i = 0; i < n; i++) tmp[i] = list[i];
delete [] list;
list = new Product[n + 1];
for (int i = 0; i < n; i++) list[i] = tmp[i];
delete [] tmp;
list[n] = newItem;  n++;

Deleting from the middle means shifting every later item one place left. Both are slow for big lists, which is what linked lists fix.

Arrays vs linked lists

7Linked lists

Each node holds data and a pointer to the next node. head points to the first node; the last node's next is NULL.

Insert at the head: order of the two steps matters

Node, traverse, insert at head

struct Node {
    int val;
    Node *next;
};
Node *head = NULL;                     // empty list

void insertHead(Node *&head, int v) {  // &: may change head
    Node *p = new Node;
    p->val = v;
    p->next = head;                    // ① link first
    head = p;                          // ② then move head
}

void print(Node *head) {
    Node *cur = head;                  // copy: keep head
    while (cur != NULL) {
        cout << cur->val << " ";
        cur = cur->next;
    }
}

Insert at tail, find

void insertTail(Node *&head, int v) {
    Node *p = new Node;
    p->val = v;  p->next = NULL;
    if (head == NULL) { head = p; return; }
    Node *cur = head;
    while (cur->next != NULL)          // stop AT the last node
        cur = cur->next;
    cur->next = p;
}
// with a tail pointer: tail->next = p; tail = p;

Node *find(Node *head, int num) {
    for (Node *c = head; c != NULL; c = c->next)
        if (c->val == num) return c;
    return NULL;
}

Delete one node, free the list

void removeVal(Node *&head, int v) {
    if (head == NULL) return;
    if (head->val == v) {              // deleting the first node
        Node *t = head;
        head = head->next;
        delete t;
        return;
    }
    Node *cur = head;                  // stop at the node BEFORE
    while (cur->next != NULL && cur->next->val != v)
        cur = cur->next;
    if (cur->next != NULL) {
        Node *t = cur->next;
        cur->next = t->next;           // bypass
        delete t;
    }
}

void deleteAll(Node *&head) {
    while (head != NULL) {
        Node *t = head;
        head = head->next;             // save next BEFORE delete
        delete t;
    }
}

Ordered insert and reverse print

void insertSorted(Node *&head, int v) {
    Node *p = new Node;  p->val = v;
    if (head == NULL || v < head->val) {
        p->next = head;  head = p;  return;
    }
    Node *cur = head;    // last node with val <= v
    while (cur->next != NULL && cur->next->val <= v)
        cur = cur->next;
    p->next = cur->next;
    cur->next = p;
}
// add 62, 89, 23, 38 → 23 38 62 89

void printReverse(Node *head) {   // recursive
    if (head == NULL) return;     // empty: print nothing
    printReverse(head->next);     // rest first
    cout << head->val << " ";     // then this node
}

Linked-list checklist

  • Test three cases: empty list, one node, many nodes.
  • Pass Node *&head when the function may change the first node.
  • To delete a node you need the node before it.
  • while (cur != NULL) runs off the end. To stop at the last node, test cur->next != NULL.
  • After bypassing a node in a remove-all loop, don't advance: the new next might match too.
  • Never move head just to traverse; use a copy.
