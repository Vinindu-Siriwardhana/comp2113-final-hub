1Compile and run

C++ is compiled: source code becomes a machine-code executable before it runs. Python is interpreted line by line.

Anatomy of hello.cpp

Commands

g++ -pedantic-errors -std=c++11 hello.cpp -o hello
./hello
-std=c++11compile as C++11
-pedantic-errorsreject code that breaks the ISO standard
-o helloname the executable (default a.out)

Reading compiler errors

  • The reported line can be wrong: the real mistake is often on an earlier line.
  • The error message itself can be misleading for the same reason.
  • Fix the first error, recompile, repeat. Later errors are often knock-on effects.
  • Delete using namespace std; and you get "'cout' was not declared in this scope".

4Operators and precedence

Higher rows run first. Within a row, left to right, except assignment (right to left). Brackets override everything.

  • Zero is false, any non-zero is true: (3 && 0) → 0, (-5 || 0) → 1, !3 → 0.
  • Short-circuit: && stops at the first false, || at the first true. n != 0 && 10 / n > 1 is safe.
  • Relational and logical results print as 1 / 0.

6Basic input and output

Streams

int age; double h, w;
cout << "Age, height, weight: ";
cin >> age >> h >> w;
cout << "Age is " << age << endl;

How cin behaves

  • The variable's type decides what is read: int reads digits, char reads one character.
  • Skips leading whitespace, stops at the next whitespace.
  • Nothing is processed until the user presses Enter.
  • cout << 1 << a; prints them stuck together: add " " yourself.
  • cin >> s on a string reads one word; getline(cin, s) reads the whole line.

7Branching

if / else if / else and ?:

if (mark >= 90) {
    cout << "A";
} else if (mark >= 80) {
    cout << "B";
} else {
    cout << "F";
}

cout << (mark >= 60 ? "passed" : "failed");

cond ? a : b is an expression with a value; if is a statement.

switch and fall-through

switch (grade) {        // int or char only
  case 'A': cout << "4.0"; break;
  case 'B': cout << "3.0"; break;
  case 'C':
  case 'D': cout << "pass"; break;  // C and D share
  default:  cout << "invalid";
}

Without break, execution carries on into the next case's code.

Dangling else

if (x > 5)
    if (y > 5)
        cout << "x and y > 5";
else                       // pairs with the INNER if
    cout << "x <= 5";      // runs when x > 5 and y <= 5

else pairs with the nearest unmatched if, whatever the indentation says. Use braces.

Legal but wrong conditions

  • if (x = 5) assigns 5, always true. Use ==.
  • if (a < b < c) compares (a<b), a 0 or 1, with c.
  • if (x > 0); the ; is the whole body; the block below always runs.
  • No braces: only the next single statement belongs to the if.

How a for loop runs

Three loops compared

LoopTestsMin runs
while (c) { }before body0

int answer = 0;
while (answer != 4) {
    cout << "2 * 2 = ";
    cin >> answer;

break and continue

for (int i = 0; i < 20; ++i) {
    if (i % 2 == 0) continue;  // skip evens
    if (i > 9) break;          // leave the loop
    cout << i << " ";
}
// 1 3 5 7 9

break leaves the nearest loop or switch. continue jumps to the next iteration (in a for loop, the update still runs).

Module 3 traps

  • double avg = sum / n; with int sum and n loses the fraction. Use sum / (double)n.
  • while (i < n); the semicolon is an empty body: infinite loop.
  • do { } while (c) needs a ; at the end.
  • An uninitialised local variable is garbage, not 0.
  • Casting truncates: (int)3.99 is 3.
  • Missing break in a switch falls through.
